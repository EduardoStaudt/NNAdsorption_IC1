# NNAdsorption IC1 — branch `network-2X1`

Esta branch mantém o código legado do IC1 no nível raiz e reúne a versão mais nova da rede em [`network_2x1/`](network_2x1/). O pacote contém inferência, pesos e os scripts necessários para gerar dados e treinar as duas redes.

Para instalar dependências, executar a inferência ou fazer um treino rápido de verificação, siga [`network_2x1/README.md`](network_2x1/README.md).

Os resultados de treino e arquivos temporários ficam em `outputs/` ou `network_2x1/saidas/` e não devem ser enviados ao Git.
